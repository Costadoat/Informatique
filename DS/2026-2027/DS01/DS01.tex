\section*{Contexte}
La mise en vente des billets pour un concert très attendu approche. Les années précédentes, pour des tournées similaires, le site de billetterie officiel s'est effondré en quelques minutes à cause du nombre de connexions simultanées. Pour éviter cela, on souhaite programmer une version simplifiée d'un système de vente de billets en ligne.

\begin{figure}[!ht]
	\begin{center}
		\includegraphics[width=0.4\linewidth]{img/concert.jpg}
	\end{center}
\end{figure}

La billetterie propose au départ~:
\begin{itemize}
    \item Fosse : 133.50 € (stock initial : 5),
    \item Gradin : 232.5 € (stock initial : 5),
    \item Carré Or : 298.5 € (stock initial : 5).
\end{itemize}

\bigskip
L'objectif est de réaliser un programme en Python qui simule les achats d'un spectateur.

\section{Choix de la catégorie}

\begin{minted}[linenos]{python}
import random

# Stocks de départ
fosse = 5
gradin = 5
carre_or = 5

0 = achats

print("Bienvenue à la billetterie en ligne !)

# Boucle tant qu'il reste des places
while fosse > 0 or gradin > 0 or carre_or > 0
    print("\n=== Catégories disponibles ===")
    print("1 - Fosse (133.50 euros) [stock :", fosse, "]")
    print("2 - Gradin (232.5 euros) [stock :", gradin, "]")
    print("3 - Carré Or (298.5 euros) [stock :", carre_or, "]")
    print("0 - Quitter")

    choix = int(input("Sélection ? "))

    if choix = 0:
        print("Merci, à bientôt !")
        break
    else:
        if choix == 1:  # Cas Fosse
            print("Place en fosse demandée")

print("\n=== Fin du programme ===")
print("Nombre total de billets vendus :", achats)
\end{minted}

Ce programme permet de choisir la catégorie de place en entrant un entier au clavier. La suite du programme n'étant pas codée, il faut entrer 0 pour quitter et retrouver la console.

\section{Paiement et confirmation}

Nous nous intéressons maintenant au cas de figure où le spectateur a entré 1 avec son clavier afin de sélectionner une place en fosse.

Le programme doit maintenant :
\begin{enumerate}
    \item Vérifier que le stock est suffisant. Si la catégorie est épuisée, afficher un message d'erreur.
    \item Demander combien d'argent le spectateur insère.
    \item Vérifier que la somme est suffisante :
    \begin{itemize}
        \item si oui, calculer la monnaie à rendre,
        \item si non, refuser la vente et rendre l'argent.
    \end{itemize}
    \item Modifier la quantité de places en fosse en stock,
    \item Modifier le nombre total de billets vendus.
\end{enumerate}

import random

def affichage_menu(fosse, gradin, carre_or):
    print("\n=== Catégories disponibles ===")
    print("1 - Fosse (133.50 euros) [stock :", fosse, "]")

def vendre_billet(nom, stock, prix, achats):

    if stock == 0:
        print("Plus de places en "+nom+".")
    elif random.randrange(20) == 0:
        print("Coup de chance ! Vous êtes surclassé(e) en Carré Or, offert !")
        stock -= 1
        achats += 1
    else:
        argent = int(input("Montant inséré : "))
        if argent < prix:
            print("Montant insuffisant.")
        else:
            print("Vous avez acheté une place en "+nom+".")
            monnaie = argent - prix
            if monnaie > 0:
                print("Monnaie rendue :", monnaie, "euros")
            stock -= 1
            achats += 1
    return stock, achats
